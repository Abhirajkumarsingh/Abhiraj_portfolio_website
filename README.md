## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/Abhirajkumarsingh/Abhiraj_portfolio_website.git
```

Move into the project directory:

```bash
cd Abhiraj_portfolio_website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

## 🚀 Deployment

The project is deployed using **Netlify** and connected to the GitHub repository.

Every time changes are pushed to the `main` branch, Netlify automatically builds and deploys the updated version.

### Deployment Flow

```text
VS Code
   ↓
Git
   ↓
GitHub
   ↓
Netlify
   ↓
Production Website
```
